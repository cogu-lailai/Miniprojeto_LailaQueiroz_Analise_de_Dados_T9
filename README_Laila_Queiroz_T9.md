## Como executar

1. Instale o Python e a biblioteca pandas (`pip install pandas`).
2. Deixe `Miniprojeto_Analise_de_Dados_T9.py` e `Base_Varejo.csv` na mesma pasta.
3. Abra o terminal nessa pasta e execute:

   `python Miniprojeto_Analise_de_Dados_T9.py`

4. O programa mostra os resultados no terminal e cria o arquivo `df_limpo.csv`.

## O que o programa faz

O programa lê a base, mostra informações gerais, procura valores vazios e duplicatas, converte a coluna de data, limpa espaços extras dos textos, trata categorias ausentes, confere a regra do número da compra, calcula estatísticas do número de filhos e faz agrupamentos por gênero, categoria e ano.
